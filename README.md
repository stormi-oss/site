# Aweron — лендинг

Статический одностраничный сайт на HTML, CSS и ванильном JS без сборки, фреймворков и внешних JS-библиотек.

## Структура

```
.
├── index.html              главная страница
├── privacy.html            политика обработки персональных данных (152-ФЗ)
├── robots.txt
├── sitemap.xml
├── favicon.svg
├── apple-touch-icon.png    180×180
├── og-image.png            1200×630, превью для соцсетей и мессенджеров
├── assets/
│   ├── css/style.css       все стили (токены в :root)
│   ├── js/config.js        ← контакты, цены, вебхук, Метрика: ВСЁ МЕНЯЕТСЯ ЗДЕСЬ
│   ├── js/main.js          интерактив, анимации, форма, cookie, JSON-LD
│   └── img/                для будущих изображений (WebP/AVIF)
└── README.md
```

## Запуск локально

Нужен любой статический сервер (открытие файла через `file://` тоже работает, но форма и шрифты ведут себя честнее через http):

```bash
python3 -m http.server 8080
```

или

```bash
npx serve .
```

Откройте http://localhost:8080

## Где что править

| Что | Где |
|---|---|
| Telegram, телефон, email, ВК | `assets/js/config.js` → `telegramUrl`, `contacts` |
| ФИО и ИНН самозанятого | `assets/js/config.js` → `legal` |
| Цены (карточки, FAQ, комплекс, «Работы») | `assets/js/config.js` → `prices` (для «Работ» — ключи `case*`) |
| URL вебхука n8n | `assets/js/config.js` → `formEndpoint` |
| Яндекс Метрика | `assets/js/config.js` → `metrikaId` |
| Тексты секций | `index.html` (секции подписаны комментариями `=== ... ===`) |
| Цвета, радиусы, шрифты | `assets/css/style.css`, блок `:root` |
| Домен (canonical, OG, sitemap) | `index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `config.js → siteUrl` — сейчас стоит `https://aweron.ru` |

Пустые контакты (телефон, email, ВК) автоматически скрываются в футере. Сумма «по отдельности» в блоке «Комплекс» считается сама из цен ИИ-администратора, сайта и автоматизации.

> Цены в `index.html` дублируются как запасной текст на случай отключённого JS и для поисковиков. Источник правды — `config.js`: при загрузке страницы значения перезаписываются. Если меняете цены надолго, поправьте и HTML (поиск по `data-price`), чтобы сниппеты в поиске совпадали.

Секция «Работы» (`#cases`): карточки проектов в `index.html`, превью — `assets/img/cases/<проект>-1200.webp` и `-640.webp` (16:10). Чтобы заменить картинку, положите новые файлы с теми же именами. Скрыть секцию целиком: `<section class="section is-hidden" id="cases">`.

## Форма заявки → n8n

### Запрос

`POST {formEndpoint}`, заголовок `Content-Type: application/json`, таймаут на клиенте 10 секунд.

```json
{
  "name": "Иван",
  "contact": "+79001234567",
  "niche": "Салон",
  "services": ["Чат-бот", "Сайт"],
  "comment": "Текст до 1000 символов",
  "consent": true,
  "page": "https://aweron.ru/?utm_source=yandex",
  "utm": { "source": "yandex", "medium": "", "campaign": "", "content": "", "term": "" },
  "ts": "2026-11-18T16:31:23.547Z"
}
```

| Поле | Тип | Описание |
|---|---|---|
| `name` | string | 2–60 символов |
| `contact` | string | телефон без пробелов и скобок (`+7XXXXXXXXXX` или `8XXXXXXXXXX`) либо ник `@username` |
| `niche` | string | одно из: `Гостевой дом / отель`, `Салон`, `Клиника`, `Ресторан`, `Турагентство`, `Другое`, или пустая строка |
| `services` | string[] | любые из: `ИИ-администратор`, `Чат-бот`, `Автоматизация`, `Сайт`, `Не знаю — нужна консультация`; может быть пустым |
| `comment` | string | до 1000 символов, может быть пустым |
| `consent` | boolean | всегда `true` (без согласия форма не отправляется) |
| `page` | string | `location.href` страницы отправки |
| `utm` | object | UTM-метки первого захода в рамках сессии (`sessionStorage`) |
| `ts` | string | время отправки на клиенте, ISO-8601 UTC |

### Ответ

Любой код `2xx` = успех («Заявка отправлена!»). Любой другой код, сетевая ошибка или таймаут = сообщение об ошибке и кнопка Telegram. Тело ответа не читается.

### Настройка в n8n

1. Узел **Webhook**: метод `POST`, Response — `Immediately` (или `Respond to Webhook` с кодом 200).
2. **CORS обязателен.** Сайт и n8n на разных доменах, а `Content-Type: application/json` вызывает preflight-запрос `OPTIONS`. В узле Webhook → Options → **Allowed Origins (CORS)** укажите домен сайта, например `https://aweron.ru`. Без этого браузер заблокирует запрос и пользователь увидит ошибку.
3. Дальше: проверка полей → запись в таблицу/CRM → уведомление в Telegram.

### ⚠️ Серверная проверка обязательна

Клиентская валидация и honeypot отсекают только случайные ошибки и простых ботов — их легко обойти, отправив запрос напрямую на вебхук. В n8n **обязательно**:

- проверять, что `name`, `contact` заданы, `consent === true`, типы полей правильные;
- обрезать длину строк (`name` ≤ 60, `contact` ≤ 40, `comment` ≤ 1000, `services` ≤ 5 элементов);
- проверять формат `contact` теми же правилами: `^(\+7|8)\d{10}$` или `^@[A-Za-z][A-Za-z0-9_]{3,31}$`;
- ограничивать частоту запросов (rate limit) — по IP на уровне nginx/прокси перед n8n или через счётчик в Redis/таблице;
- не вставлять данные заявки в HTML-сообщения Telegram без экранирования (`parse_mode: HTML` + сырой текст пользователя = поломка или инъекция разметки). Безопаснее отправлять без `parse_mode`.

## Яндекс Метрика и cookie

- Укажите цифровой ID счётчика в `metrikaId`.
- Пока ID пустой, ни Метрика, ни cookie-баннер не подключаются (аналитических cookie нет — и уведомлять не о чем).
- С заданным ID баннер показывается при первом визите. Скрипт `mc.yandex.ru/metrika/tag.js` загружается **только после** нажатия «Принять». Выбор хранится в `localStorage` под ключом `aweron_cookie_consent`.
- При успешной отправке формы вызывается цель `reachGoal('lead')` — создайте в Метрике JavaScript-цель с идентификатором `lead`.

## Деплой

Сайт полностью статический: залейте содержимое папки в корень хостинга.

- **Timeweb Cloud / Beget**: создайте сайт, загрузите файлы через файловый менеджер или SFTP в `public_html`, подключите домен и бесплатный SSL (Let's Encrypt).
- **GitHub Pages**: Settings → Pages → Deploy from branch → ветка и папка `/ (root)`. Для своего домена добавьте файл `CNAME` с доменом. Учтите: GitHub — зарубежный сервис; для сайта, собирающего ПДн граждан РФ, хостинг в России надёжнее.

После деплоя: включите HTTPS-редирект и gzip/brotli на хостинге, если он не делает этого сам.
