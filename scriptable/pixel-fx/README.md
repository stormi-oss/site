# Курсы НБРБ — пиксельный виджет для Scriptable

| Файл | Что это |
|---|---|
| `pixel-fx.js` | основной скрипт (кладётся в Gist, обновляется удалённо) |
| `loader.js` | загрузчик, 17 строк: его ставят на телефон один раз |
| `dev/` | стенд для проверки без телефона: мок API Scriptable, тесты логики, предпросмотр сцен |

## Для владельца (Роман): как выложить

1. Создайте **secret Gist** на gist.github.com с одним файлом `pixel-fx.js` и вставьте туда содержимое `pixel-fx.js`.
2. Нажмите **Raw** и скопируйте ссылку, **убрав из неё хэш коммита**:
   `https://gist.githubusercontent.com/<user>/<gist_id>/raw/pixel-fx.js`.
   Ссылка без хэша всегда отдаёт последнюю версию. GitHub кэширует её примерно на 5 минут.
3. Вставьте эту ссылку в константу `SRC` в `loader.js`. Именно загрузчик отдаёте пользователю.
4. Чтобы обновить виджет, правите Gist. Приложение подхватывает новую версию сразу, виджет — в течение 6 часов. Если нужно срочно, достаточно один раз открыть скрипт в приложении.

Загрузчик выполняет код, который лежит по ссылке. Поэтому Gist должен принадлежать только вам, а на аккаунте GitHub должна быть включена двухфакторная аутентификация. Загрузчик примет файл, только если в нём есть метка `PIXEL_FX_MAIN`. Это защищает от случайной HTML-страницы с ошибкой, но не от подмены кода.

## Инструкция для пользователя

1. Установите бесплатное приложение **Scriptable** из App Store.
2. Откройте Scriptable, нажмите **«+»** в правом верхнем углу. Создастся новый пустой скрипт.
3. Вставьте присланный код целиком (долгое нажатие → «Вставить»). Нажмите на название вверху и переименуйте скрипт в **«Курсы»**. Затем нажмите **«Готово»**.
4. Нажмите на скрипт «Курсы» в списке. Откроется мастер настройки: выберите базовую валюту, одну или две валюты для перевода, сумму и картинку. Сразу после этого покажется, как будет выглядеть виджет.
5. Вернитесь на экран «Домой». Нажмите на свободное место и удерживайте, пока иконки не начнут дрожать. Нажмите **«+»** (или «Изменить» → «Добавить виджет»), найдите **Scriptable** и выберите размер: маленький, средний или большой → «Добавить виджет».
6. Нажмите на добавленный виджет (пока иконки дрожат). В поле **Script** выберите «Курсы». В поле **When Interacting** оставьте **Run Script**.
7. *(Необязательно)* В поле **Parameter** можно указать свою пару, например `BYN:RUB,USD:100` или `RUB:BYN:1000`. Так можно поставить несколько виджетов с разными валютами. Если нажать на виджет, откроется конвертер.

Для экрана блокировки: удерживайте палец на экране блокировки → «Настроить» → экран блокировки → блок виджетов → Scriptable. Дальше так же, как в шагах 6–7.

### Формат Parameter

`БАЗА:ЦЕЛИ:СУММА:СЦЕНА`. Любую часть можно пропустить, тогда возьмётся значение из настроек.

- `BYN:RUB,USD:100` — 100 BYN в RUB и USD
- `KZT:BYN:1000` — 1000 тенге в белорусские рубли
- `BYN:USD,EUR,RUB::city` — три валюты, ночной город (третья валюта видна на большом виджете)
- Сцены: `sign` — табличка в поле, `cloud` — облако, `city` — ночной город.

## Что проверить на телефоне

- [ ] **Первый запуск**: проходит мастер из 4 шагов, после него появляется предпросмотр. При повторном запуске открывается меню «Конвертер / Настройки / …».
- [ ] **Все размеры**: маленький, средний, большой, экран блокировки (прямоугольный и строка). На iPad — ещё extraLarge. Цифры не обрезаются и не наезжают на рамку таблички.
- [ ] **Сверка с nbrb.by**: для пар с RUB (курс за 100), CNY (за 10) и KZT (за 1000) суммы совпадают с калькулятором НБРБ с точностью до копейки.
- [ ] **Тап по виджету** открывает конвертер с парой именно этого виджета. Проверить кнопки «Скопировать» (вставить в Заметки), «Поменять направление» и ввод суммы с запятой (`99,90`).
- [ ] **Parameter**: `BYN:RUB,USD:100` применяется; заведомо ошибочный `ABC` показывает понятную ошибку, а не крах.
- [ ] **Офлайн**: включить авиарежим → «Обновить курсы» в меню → на виджете должна появиться надпись «офлайн · курс от ДД.ММ». Ещё одна проверка: удалить скрипт, поставить заново в авиарежиме — должна появиться понятная ошибка «Нет связи с НБРБ…».
- [ ] **Ночь / сезоны**: в меню есть «Тест сцен» — там выбираются сезон, время суток, тренд и тема. Второй способ: в коде `pixel-fx.js` задать `DEBUG_NOW = '2026-01-15T22:30:00'` и проверить на реальном виджете (не забыть вернуть `null`).
- [ ] **Тёмная тема iOS**: сцена приглушается. Не уверен, что `Device.isUsingDarkAppearance()` правильно работает внутри виджета: по отзывам, он может всегда возвращать «светлую». Проверить.
- [ ] **Обновление**: поменять что-нибудь в Gist (например, `VERSION`) → открыть скрипт в приложении → в меню видна новая версия.
- [ ] **Загрузчик без сети**: авиарежим → виджет и приложение работают из сохранённой копии.
- [ ] **Тренд**: стрелки ▲/▼/= и погода (солнце / дождь / облачно) совпадают с изменением курса относительно вчера на nbrb.by.

## Проверка без телефона

```bash
node dev/test-logic.mjs      # точность расчётов, Cur_Scale, параметр, кэш, офлайн
node dev/test-widget.mjs     # main() в режиме виджета, все размеры
python3 -m http.server 8765  # затем http://localhost:8765/dev/preview.html
```

Параметры `preview.html`: `?fam=small,medium,large&scene=sign,cloud,city&season=winter&tod=night&trend=down&p=KZT:BYN:1000&dark=1&offline=1`.
Стенд — это эмуляция в браузере: шрифт и метрики текста немного отличаются от iOS.

## Технические заметки

- Курсы храним как целые числа ×10⁶, суммы — в копейках. Всё считаем в `BigInt` и округляем только при выводе: курс до 4 знаков, сумма до 2. Кросс-курс считается через BYN, `Cur_Scale` берётся из ответа API.
- Кэш хранится в `Documents/pixel-fx/rates-cache.json`, настройки — в `settings.json` (`FileManager.local()`). В приложении это видно как папка `pixel-fx`.
- Сеть: НБРБ меняет курс раз в сутки, поэтому, если в кэше уже сегодняшний курс, запросов не будет. Историю за 14 дней скрипт догружает через `/exrates/rates/dynamics/{Cur_ID}` не чаще раза в день. Таймаут — 10 с плюс собственный таймер-страховка.
- Ответ `dynamics` не содержит `Cur_Scale`, поэтому для истории берётся сегодняшний масштаб. Если НБРБ поменяет масштаб валюты (было с RUB), график за переходные дни будет неточным до следующего обновления.
- Формат API взят из документации НБРБ. Из среды разработки api.nbrb.by был недоступен, поэтому на живом ответе он **не проверен**. Это первое, что нужно сверить на телефоне.
