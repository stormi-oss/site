# IT-Мир Бипа — задания по информатике для ребёнка

Отдельный раздел сайта: `/it-kids/`. Чистые HTML/CSS/JS, без сборки, библиотек и внешних запросов.
Прогресс, план и заметки хранятся **только в браузере** (localStorage): на сервер ничего не уходит, персональные данные не собираются.
Страница закрыта от поисковиков (`noindex`).

## Запуск

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080/it-kids/ — или просто залить папку на хостинг вместе с сайтом.
Открытие файла через `file://` тоже работает.

## Что сделано с учётом особенностей ребёнка

- **Одинаковая раскладка на всех экранах:** задание сверху → поле → сообщение → кнопки «Подсказка / Сначала / Проверить».
- **Нет таймеров, жизней, штрафов и красных «НЕПРАВИЛЬНО».** Ошибки — мягким жёлтым, с конкретной подсказкой: «На блоке №3 Бип упёрся в стену», «Не совпадает 2 клетки — я обвёл их пунктиром».
- **Сначала проверка, потом успех.** Окно успеха спокойное, без конфетти и вспышек.
- **Звук выключен по умолчанию**, анимации можно выключить, есть крупный текст (раздел «Взрослым»). Учитывается системная настройка «уменьшить движение».
- **План урока** на главной — визуальное расписание с галочками: ребёнок видит, сколько осталось и что дальше.
- **Кнопка «🌿 Отдых»** всегда в шапке — дыхательный круг, возврат туда, откуда ушли.
- Все задания открыты сразу (без замков) — взрослый сам решает порядок. Следующее непройденное подсвечено.
- Управление с клавиатуры и экранного диктора: кнопки, подписи `aria`, стрелки на клавиатуре добавляют блоки роботу.

## Для репетитора («⚙️ Взрослым»)

- Авто-план на 3/5/8 заданий (по одному из разных миров) или ручной: включить «Режим составления плана» → в каждом мире кнопки «+ в план».
- Таблица прогресса: пройдено, сколько раз проверка не прошла, сколько подсказок, на каких заданиях было трудно (3+ ошибки).
- «Скопировать отчёт» — текст для родителей в мессенджер.
- Заметки по ученику (только в этом браузере).

Прогресс привязан к браузеру. Если ребёнок занимается на разных устройствах, на каждом свой прогресс.

## Как добавить задание

Откройте `levels.js`, найдите нужный мир и допишите объект в массив `levels` по образцу соседних. Затем проверьте:

```bash
node it-kids/tools/check-levels.js
```

Скрипт проверяет структуру и **решаемость**: для робота ищет кратчайшее решение и сверяет с лимитом блоков, для выключателей перебирает все комбинации и т.д.

Шпаргалка по форматам:

- **Робот:** `map` — строки, `R` — старт, `G` — флажок, `*` — звезда, `#` — стена. `repeat: true` включает повторы, `maxBlocks` — лимит блоков, `preset` — готовая программа с ошибкой (`'R'` или `['R', 3]`).
- **Пиксели:** `target` — строки, `.` — белый, цвета: `k r y g b o p n s` (чёрный, красный, жёлтый, зелёный, синий, оранжевый, розовый, коричневый, голубой). `mode`: `copy` / `coords` / `binary` (только один цвет) / `rle`. Ширина — не больше 8.
- **Лампочки:** `mode: 'set' | 'read'`, `bits` (4 или 5), `value`.
- **Порядок:** `items` — в правильном порядке, перемешиваются сами. `adjacentOnly: true` — менять только соседей.
- **Коробки:** `bins` + `items` с полем `bin`.
- **Выключатели:** `switches: ['A','B','C','D']` (синий, красный, зелёный, жёлтый), у ламп `rule` — `'A'`, `['and', ...]`, `['or', ...]`, `['not', x]` и `want: true/false`.
- **Шифры:** `mode: 'table'` + `table: [[значок, буква], ...]`; `caesar` + `shift`; `reverse`.
- **Узоры:** `full` — весь ряд, `blanks` — сколько последних клеток спрятать, `extra` — лишние варианты.
- **Клавиатура:** `text` — строчные русские буквы, цифры, пробел.
